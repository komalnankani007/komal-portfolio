# Komal Nankani — Portfolio

A responsive React + Vite portfolio based on the supplied résumé, inspired by the reference portfolio's clear section structure (hero, about, experience, selected work, skills, education and contact) while using an original dark, lime-accented visual style.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Upload this project to a GitHub repository.
2. Import the repository in Vercel.
3. Vercel should detect Vite automatically. Build command: `npm run build`; output directory: `dist`.

## Personalize before publishing

- Confirm your current location and whether you want to show “Open to the right opportunity”.
- Add GitHub and public project/demo links if you want them shown. The project cards currently describe representative work supported by the résumé and intentionally do not invent public demos.
- The résumé PDF is in `public/Komal_Nankani_CV.pdf`.
- Contact details and profile URL are at the top of `src/main.jsx`.
- Main content is in `src/main.jsx`; design tokens and responsive styles are in `src/styles.css`.
